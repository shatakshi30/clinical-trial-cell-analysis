# Immune Response Explorer

This project analyzes immune-cell populations from a clinical trial for Loblaw
Bio. It loads the supplied cell-count data into a relational SQLite database,
calculates the relative frequency of five immune-cell populations, compares
miraclib responders with non-responders, and summarizes a requested baseline
melanoma cohort in an interactive Streamlit dashboard.

## Live dashboard

The public dashboard link will be added here after deployment.

> The local address `http://localhost:8501` is not a public dashboard link.

## Quick start in GitHub Codespaces

Open the repository in GitHub Codespaces, then run these commands from the
repository root:

```bash
make setup
make pipeline
make dashboard
```

The commands perform the following work:

- `make setup` installs the Python packages listed in `requirements.txt`.
- `make pipeline` creates `cell_counts.db`, loads `cell-count.csv`, and runs
  the analyses for Parts 2–4.
- `make dashboard` starts the Streamlit server on port `8501`.

When Codespaces reports that port `8501` is available, select **Open in
Browser** to view the dashboard. Keep the dashboard command running while
using the application.

## Run locally

Python 3.9 or newer is recommended. Create and activate a virtual environment,
then run the same Make targets:

```bash
python -m venv .venv
source .venv/bin/activate
make setup
make pipeline
make dashboard
```

The local dashboard will be available at
[`http://localhost:8501`](http://localhost:8501).

## Part 1: Data management

Running `python load_data.py` creates `cell_counts.db` in the repository root
without requiring command-line arguments. The relational schema contains:

- `subjects`: one row per clinical-trial subject
- `samples`: one row per biological sample, linked to its subject
- `cell_counts`: one row per sample and immune-cell population

The loader is safe to rerun: it rebuilds the source tables before loading all
10,500 samples from `cell-count.csv`.

## Part 2: Relative cell-population frequencies

For every sample, the pipeline sums the five cell-population counts to obtain
`total_count`. It then calculates:

```text
percentage = population count / total sample count × 100
```

The resulting `cell_frequencies` table has the required columns:

```text
sample, total_count, population, count, percentage
```

It contains 52,500 rows: five population rows for each of 10,500 samples. The
dashboard provides a searchable, filterable, and downloadable view of this
table.

## Part 3: Responder comparison

The Part 3 cohort includes only records satisfying all of these conditions:

- condition: melanoma
- treatment: miraclib
- sample type: PBMC
- response: `yes` or `no`

The eligible cohort contains 331 responders and 325 non-responders. Each
subject has samples at days 0, 7, and 14. To avoid counting repeated samples
from one subject as independent observations, the analysis first calculates
one mean percentage per subject and cell population.

For each of the five populations, the pipeline performs a two-sided
Mann–Whitney U test comparing responders with non-responders. It adjusts the
five p-values using the Benjamini–Hochberg false-discovery-rate procedure and
reports medians, median differences, adjusted p-values, and rank-biserial
effect sizes.

### Statistical conclusion

No population is statistically significant at the conventional 5% FDR
threshold. CD4 T-cell frequency is an exploratory finding at a 10% FDR
threshold:

```text
Raw p-value:       0.012
Adjusted p-value:  0.062
```

This CD4 T-cell result is treated as suggestive rather than confirmatory and
would require independent validation. This analysis identifies associations;
it does not by itself validate a predictive model for future patients.

## Part 4: Subset analysis

The baseline subset includes melanoma PBMC samples collected at time 0 from
patients treated with miraclib. It contains 656 samples and subjects.

| Requested summary | Category | Count |
|---|---|---:|
| Samples by project | prj1 | 384 |
| Samples by project | prj3 | 272 |
| Subjects by response | Non-responder | 325 |
| Subjects by response | Responder | 331 |
| Subjects by sex | Female | 312 |
| Subjects by sex | Male | 344 |

For melanoma male responders at time 0, across all sample and treatment types,
the average raw B-cell count is:

```text
10206.15
```

The brief mentions **quintazide**, but quintazide is not a treatment value in
the supplied dataset. The available treatment values are `miraclib`,
`phauximab`, and `none`, so quintazide is not used as a filter.

## Dashboard contents

The dashboard has one overview and three analysis tabs:

- **Part 2 — Frequencies:** filter and download the complete frequency table.
- **Part 3 — Response Analysis:** compare response groups with five boxplots
  and review the statistical-results table.
- **Part 4 — Baseline Subset:** inspect project, response, and sex summaries,
  the baseline sample table, and the requested B-cell average.

## Reproducing outputs manually

The Makefile is the recommended interface, but the pipeline can also be run
directly:

```bash
python load_data.py
python analysis.py
python -m streamlit run dashboard.py --server.address 0.0.0.0 --server.port 8501
```

Run the commands from the repository root and in the order shown. The analysis
scripts are deterministic for the supplied CSV file.
